== Description ==

Nusantara Stay is a modern WordPress Full Site Editing (FSE) block theme engineered for luxury hospitality, boutique stays, and villas. It features custom block patterns, theme.json design tokens, and booking UI components.

== Installation ==

1. Upload this theme to your WordPress /wp-content/themes/ directory.
2. Activate Nusantara Stay in Appearance › Themes.
3. Edit the homepage and every section in Appearance › Editor.
